HTML-elementit

HTML määrittelee verkkosivun rakenteen ja sisällön. Elementit kertovat selaimelle, mitä kukin sisältö on: esimerkiksi otsikko, kappale, kuva, linkki tai taulukko. Elementit kirjoitetaan yleensä avaavan ja sulkevan tagin väliin, kuten <p>Teksti</p>

HTML-attribuutit

Attribuutit antavat HTML-elementeille lisätietoja tai ominaisuuksia. Ne kirjoitetaan elementin avaavaan tagiin, ja niiden arvo määritellään yleensä lainausmerkeissä. Esimerkiksi class ja id auttavat tyylien kohdistamisessa, kun taas href kertoo linkin kohteen ja src kuvan sijainnin.

CSS-ominaisuudet

CSS määrittelee verkkosivun ulkoasun ja asettelun. CSS-ominaisuuksilla voidaan muuttaa esimerkiksi värejä, fontteja, kokoja, välistyksiä ja elementtien sijoittelua.

CSS-valitsin Käyttö Esimerkki

#id Valitsee id:n #header { ... }
.class:hover Pseudoluokka, esim. hover-tila .button:hover { ... }
elementti Valitsee html-elementin h1 { ... }
elementti.class Valitsee vain elementit joille on määritelty kyseinen luokka p.important { ... }
CSS-valitsimet

Valitsimet määrittelevät mihin HTML-elementteihin CSS-tyylit kohdistetaan. Elementtiselektorilla voidaan valita esimerkiksi kaikki <p>-elementit, .class-selectorilla tiettyyn luokkaan kuuluvat elementit ja #id-selectorilla yksi tietty elementti. Pseudoluokat, kuten :hover, mahdollistavat tyylien muuttamisen elementin eri tiloissa.
